# 三国志 · 群雄割据

一款玩法参照《三国志11》的网页策略游戏：在一张六角格大地图上经营都市、招揽武将、调兵遣将，内政与战争在同一张地图上即时展开，目标是统一天下。

纯 HTML5 Canvas + 原生 JavaScript，无需构建、无第三方依赖。

## 运行

直接用浏览器打开 `index.html` 即可；也可以起一个本地静态服务器：

```bash
npx http-server -p 8080 .
# 浏览器访问 http://localhost:8080
```

## 主要玩法

| 系统 | 内容 |
| --- | --- |
| 剧本 | 194 年「群雄割据」：19 路势力（曹操、袁绍、刘备、孙策、吕布、刘表、刘璋、马腾……），42 座都市 + 5 座关隘 + 16 座港口 |
| 地图 | 约 80×60 六角格：平原、荒地、森林、山地、峻岭、黄河/长江等河川、道路、海岸线；关隘扼守要道（虎牢关、函谷关、壶关、武关、剑阁） |
| 时间 | 每回合一旬；每月初收金，每季首月收兵粮（七月秋收加倍） |
| 行动力 | 内政、出征、人事、外交均消耗势力行动力，每旬按都市数回复 |
| 都市内政 | 在都市周围地块建设设施：市场、农田、兵营、锻冶所、厩舍、工房；征兵、训练、巡察、生产兵装、搜索、委任 |
| 武将 | 约 250 名武将，五维（统率/武力/智力/政治/魅力）、六项兵种适性（S/A/B/C）、30 余种特技（飞将、神将、神算、火神、铁壁、名声……）；后期人才按年份登场（诸葛亮、司马懿、陆逊……） |
| 部队 | 最多 3 名武将一队；剑、枪、戟、弩、骑、冲车、井阑、投石、运输队；兵种相克；ZOC 区域控制；进入河川变为舟船 |
| 战法 | 突刺/螺旋突/二段突、横扫/旋风、乱射/贯射/火矢、突击/突破/突进、攻城、放射、投石；暴击可触发单挑 |
| 计略 | 火计、扰乱、伪报、镇静，成功率取决于智力，洞察/深谋者免疫 |
| 攻城 | 削减兵力与耐久，兵力归零即攻陷；守城武将或逃或被俘；都市每旬射击相邻敌军 |
| 人事 | 登用在野武将、挖角他国武将、处置俘虏（登用/释放/处斩）、褒赏、召唤；忠诚过低者可能出奔 |
| 外交 | 亲善、同盟、停战、劝降；电脑势力也会主动遣使 |
| 港口与水军 | 沿黄河、长江、汉水与海岸的港口可驻军、可攻占；造船厂生产斗舰、楼船，出征时配备舰船；水上改用水军战法（冲突、乱射、火船），斗舰/楼船可航行近海；火攻战船会在相邻船只间蔓延 |
| 官职与爵位 | 君主按都市数晋位：太守→刺史→州牧→公→王→皇帝，决定可授最高官职并增加行动力；武将一至七品武官（大将军……偏将军）与文官（军师、尚书令、侍中、中书令），决定统兵上限与能力加成，需积累功绩 |
| 历史事件 | 迎奉天子、袁术称帝、千里走单骑、古城相会、孙策遇刺、袁绍病逝、三顾茅庐、刘表病逝、东南风起、张松献图；以及蝗灾、疫病、丰收、山贼、商队、江河泛滥、名士来访等随机事件 |
| **工事（特色）** | **开沟**：挖壕沟阻滞敌军（兵器无法通过），接通河流自动灌满成为水渠，可把水引向敌城；**陷坑**：隐蔽陷阱，敌军踏入即受损停步；**筑堤**：截流蓄水，水位逐旬上涨、雨季加倍，满水有溃堤之险；**决堤**：洪水沿河道与水渠泛滥，淹没低地部队、冲毁城墙——水淹七军、引水灌城（悬停堤坝可预览淹没范围与敌我损失）；**填沟** |
| **托管** | 手动 / **内政托管**（开发、征兵、训练、巡察、生产、搜索、登用、俘虏、褒赏、官职任命交给部下，主公只管出征与指挥）/ **全托管**（军政全交 AI）；单城「委任」与内政托管效果相同 |
| AI | 电脑势力自主经营内政、输送兵力、择弱而攻、防御反击、指挥部队使用战法与计略、配备战船、布设陷坑、伺机决堤 |
| 存档 | 浏览器本地 3 个存档位 + 每回合自动存档 |

## 画面与界面（仿三国志11）

- 水墨风大地图：地形晕染过渡、纸纹墨晕、立体山脉与丘陵、平滑河道、成片松林、海岸浪花；六角网格默认隐藏，移动部队时显示（「系统」可设为常显）
- 城池画成带城墙、角楼、城门、屋顶与势力旗帜的小城；关隘为关城、港口有码头泊船；城外设施为市集、田地、营帐、锻冶坊等建筑；野战建筑有阵、砦、箭楼、石兵八阵造型
- 部队画成士兵小队（枪、戟、弩、骑、冲车、井阑、投石、辎重车）与主将姓氏军旗，水上为带帆战船（斗舰单桅、楼船双桅带楼）
- 右下指令栏（都市 / 军事 / 人事 / 外交 / 技巧 / 情报 / 军师 / 系统 / 结束），点击弹出子菜单；左下信息卡显示太守或主将立绘；右上小地图；顶部滚动战报
- 点击部队在其旁弹出指令菜单：移动、攻击、战法 ▸、计略 ▸、工事 ▸、建设 ▸、待命、行军；选择后顶部提示点选目的地或目标

## 三国志11 式玩法补充

| 系统 | 内容 |
| --- | --- |
| 技巧研究 | 技巧点来自作战、内政功绩与各城月积累；八大分支（枪、戟、弩、骑、兵器、水军、内政、军制）各三阶，如精锐枪兵、强弩（射程 1-3）、良马产出、霹雳车、火船、屯田制、城墙强化、强行军、阵地构筑、八阵图 |
| 野战建筑 | 部队在相邻格建设：阵（相邻友军防御 +15%、回复）、砦（+25% 且射击，需「阵地构筑」）、箭楼（自动射击两格内敌军）、石兵八阵（迷乱两格内敌军，需「八阵图」）；有耐久可被攻毁，AI 也会修建 |
| 单挑 | 触发后亲自操作：攻击 / 全力一击（高伤害但可能落空）/ 防御（减伤蓄气势）/ 必杀（气势满）/ 撤退；落马方部队受损，武将可能被俘 |
| 舌战 | 登用、同盟、停战、劝降时可选择舌战：道理 克 利害、利害 克 感情、感情 克 道理，同类比点数，辩胜则必定成功 |

## 武将立绘演出与军师建言

- 发动战法、计略、决堤时，武将立绘从侧边切入并喊出台词（关羽「看我青龙偃月刀！」、张飞「燕人张翼德在此！」……），会心一击时更大更醒目；敌军对我方暴击时从右侧切入
- 征兵、开发、生产等内政完成后，执行武将带头像汇报
- 每回合开始，军师（或智力最高的谋士）带头像献策：敌军逼近、兵粮告急、空城可取、贤才可登用、俘虏待处置、忠诚过低等，点击建议即跳转；顶栏「军师」按钮可随时呼出
- 历史事件弹窗显示相关人物立绘
- 「系统」中可设置立绘显示（全部 / 仅会心 / 关闭）与是否自动献策

## 武将头像编辑

打开 `editor.html`（标题画面与「系统」菜单中也有入口）：

- 按姓名搜索、按势力筛选、只看有/无头像的武将
- 点击武将后选择图片、拖入图片或 Ctrl+V 粘贴，拖动调整位置、滚轮缩放，裁成 3:4 保存
- 批量导入：一次选择多张以武将姓名命名的图片（如 `关羽.png`），自动匹配并居中裁切
- 导出 / 导入头像包（JSON），便于备份与分享
- 头像保存在本机浏览器（IndexedDB），游戏中的部队面板、武将列表、地图部队标记与单挑画面会自动使用；编辑页保存后，已打开的游戏页会即时更新

## 操作

- 点击都市后用右下指令栏下令；点击己方部队在其旁弹出指令菜单，选「移动」后点蓝色格，选攻击 / 战法 / 计略 / 工事 / 建设后点红色目标（悬停可预览成功率与伤害）
- 拖动或方向键 / WASD 平移地图，滚轮缩放，点击右下小地图快速跳转
- `E` 结束回合，`N` 切换到下一支待命部队，`Esc` / 右键 取消
